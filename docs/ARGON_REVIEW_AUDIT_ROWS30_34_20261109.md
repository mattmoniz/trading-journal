## Discrepancy found while auditing (not Argon's) - RESOLVED
The brief said "P&L in points as stored" and a 2.0 pt cost. Checked on VALUE_FADE / GLOBEX_LEVEL real rows (max deviation 0.00): `active_setups.actual_pnl` is in DOLLARS per 1 MNQ = side x (price_at_resolution - price_at_detection) x 2 - 2, i.e. the cost is $2 = 1.0 pt, and every per-row figure in the brief (VALUE_FADE -1.79 / -5.24, STOP_SWEEP +8.5, C_PAIRED +14.7, etc.) is DOLLARS per row, half that in points. Argon's point-based statements inherit the error (e.g. "6.5x the 2.0 pt cost"). Any replay must compare in dollars (or halve to points) and use cost $2 = 1.0 pt; the vacuum sim's own 2.0 pt (if it uses points) must be checked before comparing it with row P&L. The co-025 bar is expressed in points: convert d from dollars by dividing by 2.
