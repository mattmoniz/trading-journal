# Vacuum thrust as an ENTRY TRIGGER for the system's other setups (row 34). REGISTERED 2026-11-09 (user: "consider starting the trade with a vacuum entry"); NOT BUILT, NOT RUN

Origin: the capitulation overlay (row 30) uses a vacuum thrust to leave a trade; the user asks whether the same thrust could START it. Related: the turn signal (row 32) already enters on a qualified vacuum ignition at a turn point; this row asks the narrower question for the existing level / flush / continuation setups.
## Idea (to be pinned down by Phase 1 before any outcome)
Instead of entering a setup row at its own fire (limit at the level / its trigger), enter at the NEXT bar open after the first same-direction ROC10 expansion onset inside the row's life (confirmation entry). Stop and target keep their original PRICE levels (not distances), so the arm differs from the row only in entry price and time.
## Mandatory design points (frozen now)
- Entry-price-only control arm (hr-042): the row's own exit applied from the row's own entry vs from the thrust-bar entry on the same stop/target levels; a better result must beat the arm that merely enters later at a worse/better price without the thrust.
- Did-it-fill check (cv-070); rows whose stop or target is hit BEFORE the thrust are the NON-entries and must be counted as lost trades (opportunity loss), never dropped: the paired statistic is per ROW of the class, with no-thrust rows contributing 0 for the arm (it never traded) against the row's actual P&L, and a second statistic on traded rows only.
- Variants (descriptive until counted): any thrust vs EXTENDED thrust (top tercile, same definition as rows 28/29/30); RTH vs Globex; by bet class (VALUE_FADE, GLOBEX_LEVEL, CONTINUATION_LEGACY, FAILED_SWEEP_REVERSAL).
- Both RTH and Globex (hr-002). No lookahead (hr-020): the thrust bar's END is the earliest knowable time.
