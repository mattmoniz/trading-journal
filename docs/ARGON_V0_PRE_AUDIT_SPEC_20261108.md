## 3. Distribution-Derived Feature Definitions (Zero Static Thresholds)

Per repository hard rule, **every trigger, velocity gate, stop distance, protection cap, and timeout is derived from a trailing rolling distribution ($\mu \pm k\sigma$ or trailing empirical quantile)**—never a hardcoded price, second, or raw ratio constant. All EMAs use $\alpha = \frac{2}{L+1}$; all rolling `StdDev` use `ddof = 0`. RTH (`09:35:00–15:50:00` ET) and Globex (`18:30:00–09:25:00` ET) maintain **strictly separate session-matched quantile histories** and are evaluated from scratch as independent tracks (never pooled).

### 3.1 True Range & Price Structure Baseline
$$TR_t = \begin{cases} H_{\text{adj}, t} - L_{\text{adj}, t} & \text{if } \text{bars\_since\_reset}_t == 0 \\ \max(H_{\text{adj}, t} - L_{\text{adj}, t}, |H_{\text{adj}, t} - C_{\text{adj}, t-1}|, |L_{\text{adj}, t} - C_{\text{adj}, t-1}|) & \text{otherwise} \end{cases}$$
$$EMA\_TR_t = \text{EMA}(TR_t, L=10), \quad EMA\_Price_{20, t} = \text{EMA}(C_{\text{adj}, t}, L=20)$$

### 3.2 Backtest-Live Identical Tick-Duration Depth Proxy (`EMA_Depth_t`)
Both `.scid` replay and live execution compute $\text{RawDepth}_t$ identically from trade-count and bar duration (`dom_depth_close` is never substituted into $\text{RawDepth}_t$):
$$\Delta t_t = \max\left(\text{end\_sec}_t - \text{start\_sec}_t, \text{Quantile}_{0.01}(\Delta t_{\text{prior 20 sessions}})\right)$$
$$\text{RawDepth}_t = \text{num\_trades}_t \times \ln(\Delta t_t + 1.0), \quad EMA\_Depth_t = \text{EMA}(\text{RawDepth}_t, L=10)$$

### 3.3 Subgraph 1: `Ratio` (Unsigned Vacuum Speedometer)
$$\text{Ratio}_t = \frac{EMA\_TR_t}{\max(EMA\_Depth_t, 10^{-6})}$$
$$\text{Ratio\_Mid}_t = \text{SMA}(\text{Ratio}_t, 50), \quad \text{Ratio\_Std}_t = \text{StdDev}(\text{Ratio}_t, 50, \text{ddof}=0)$$
$$Z_{\text{Ratio}, t} = \frac{\text{Ratio}_t - \text{Ratio\_Mid}_t}{\max(\text{Ratio\_Std}_t, 10^{-9})}$$

### 3.4 Subgraph 2: Clock-Hour Matched Tape Velocity (`Activity_Ratio_t`)
Using the prior 20 completed sessions' mean bar duration for the **same ET clock hour** ($\text{BaseDur}_{\text{hour}(t)}$, strictly prior sessions—zero lookahead) and the trailing 50-bar local mean $\text{Dur\_SMA}_t = \text{SMA}(\Delta t_t, 50)$:
$$\text{Activity}_t = \frac{\text{BaseDur}_{\text{hour}(t)}}{\Delta t_t}, \quad Z_{\text{Dur}, t} = \frac{\Delta t_t - \text{Dur\_SMA}_t}{\max(\text{StdDev}(\Delta t_t, 50, \text{ddof}=0), 10^{-9})}$$
- **`is_fast_tape[t]` (Session-Matched Rolling Distribution Gate):**
  - **RTH Track (`09:35:00`–`15:50:00` ET):** $\text{is\_fast\_tape}_t \iff (\text{Activity}_t \ge 1.0) \land (Z_{\text{Dur}, t} \le -0.25)$.
  - **Globex Track (`18:30:00`–`09:25:00` ET):** $\text{is\_fast\_tape}_t \iff (\text{Activity}_t \ge \text{Quantile}_{0.75}(\text{Activity}_{\text{GBX}, 20\text{d}})) \land (Z_{\text{Dur}, t} \le -0.50)$.
  - **Outside Active Track / In Dead Zones:** $\text{is\_fast\_tape}_t = \text{False}$.

### 3.5 Subgraph 3: Gap-Free `ROC` Compass & Order-Flow Alignment
$$ROC_{10, t} = X_t - X_{t-10}, \quad ROC_{3, t} = X_t - X_{t-3}$$
$$\text{ROC10\_Mid}_t = \text{SMA}(ROC_{10, t}, 50), \quad \text{ROC10\_Std}_t = \text{StdDev}(ROC_{10, t}, 50, \text{ddof}=0)$$
$$Z_{\text{ROC}_{10}, t} = \frac{ROC_{10, t} - \text{ROC10\_Mid}_t}{\max(\text{ROC10\_Std}_t, 10^{-9})}, \quad Z_{\text{ROC}_3, t} = \frac{ROC_{3, t} - \text{SMA}(ROC_{3, t}, 50)}{\max(\text{StdDev}(ROC_{3, t}, 50, \text{ddof}=0), 10^{-9})}$$
- **Close Location & 3-Bar Delta Alignment (Rolling Quantile Anti-Wick Filter):**
  Let $\text{CLV}_t = \frac{C_t - L_t}{\max(H_t - L_t, \text{tick\_size})}$ and $\Delta_{3, t} = \sum_{i=0}^{2} \text{delta}_{t-i}$:
  - $\text{Flow\_Aligned\_Long}_t \iff \left(\text{CLV}_t \ge \text{Quantile}_{0.60}(\text{CLV}_{200, t-1})\right) \land (\Delta_{3, t} > 0)$
  - $\text{Flow\_Aligned\_Short}_t \iff \left(\text{CLV}_t \le \text{Quantile}_{0.40}(\text{CLV}_{200, t-1})\right) \land (\Delta_{3, t} < 0)$

### 3.6 Pre-Breakout 15-Bar True-Range Compression (`Is_Absorbed_t`)
Over the strictly preceding 15 completed bars `[t-15 .. t-1]` ($7,500$ `NQ` contracts):
$$\text{BoxHigh}_{t-1} = \max_{k=1..15}(H_{\text{adj}, t-k}), \quad \text{BoxLow}_{t-1} = \min_{k=1..15}(L_{\text{adj}, t-k}), \quad \text{BoxRange}_{t-1} = \max(\text{BoxHigh}_{t-1} - \text{BoxLow}_{t-1}, \text{tick\_size})$$
$$\text{Compression}_{t-1} = \frac{7500.0}{\text{BoxRange}_{t-1}} \times \left(1.0 + \frac{\left|\sum_{k=1}^{15} \text{delta}_{t-k}\right|}{7500.0}\right)$$
$$\text{Is\_Absorbed}_t \iff \text{Compression}_{t-1} > \text{Quantile}_{0.90}\left(\{\text{Compression}_{t-201}, \dots, \text{Compression}_{t-2}\}\right)$$

   - Collapse same-`cycle_id` trades via `collapseClusterSiblings()`, then compute seeded `dayBlockedBootstrapCI(..., iters=3000)` and `computeRigor()` (`distinctDates`, `top5DayPct <= 50%`, `three_way_stable == true`, `zScores`, `boundaryStraddle`) plus `computeReplication()` across non-selected variants.
