# NQ stitch-guard inventory of scheduled minute-bar readers (2026-11-10)

Task 1 of docs/SONNET_SPEC_FABLE_FOLLOWUPS_20261110.md. Question: which scheduled scripts that read `price_bars_primary` can take a price difference, return, hold or level across a contract stitch (jumps of 165 to 513 points that never traded), and which read the bad-bar dates (`scripts/lib/data/nq_roll_stitches.json`: 15 stitches, 85 bad-bar dates, 76 of them the mixed-row dates 2025-05-29..2025-08-25).

## How this was made (and what it does not prove)
- File list: every script named in scripts/run_weekly_backtests.sh, run_daily_calibration.sh, run_context_analysis.sh, run_confluence_backtest.sh, run_session_bias.sh, scripts/amt_context/forecast_loop_weekly.sh, plus the four cron-frequent scripts: 160 scheduled files, **106 read minute bars** (directly or through a local library; mentions through `server/db.js` and `server/config/setupTypes.js` do not count). Files naming the bar tables across the repo: 601 under scripts/ and server/ (1,320 with scratch/).
- Classification is from the actual bar query of each script (shape, date floor, session hours) plus a keyword scan (overnight / Globex / prior-day / gap / lookback). I read the bar-query block of all 106 and the loop of the 5 I edited. I did **not** trace every script line by line; where a bar read goes through a service or library the reason says "not traced". Read CAN-CROSS as "will cross if an event sits near a stitch", not as a measured count of bad events (no outcome was read to make this inventory).
- A script gets exactly one class, by priority CAN-CROSS, then READS-BAD-WINDOW, then SAFE-BY-CONSTRUCTION. Every RTH-only (09:30-16:00) reader with no date floor after 2025-08-25 is READS-BAD-WINDOW, because all 15 stitch instants are at 00:00 or 18:00 (outside RTH) but the mixed-row dates are inside it.
- Guard column: "data-derived stitch list" = the new helper; "calendar rule only" = `getNqRollWeekDates` / `isInsideNqRollWeek` / roll-week lists, which miss 8 of the 15 stitches.
- The class shown is the class **before** the edits made in this task.
