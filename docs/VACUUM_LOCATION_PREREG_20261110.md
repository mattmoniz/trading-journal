# Vacuum: where does the move happen, and does location (open air vs congestion) matter? (pre-registered 2026-11-10 night, BEFORE any outcome of these tests is read; user: vacuum only)
Origin: Argon's vacuum reply (audited in docs/ARGON_REVIEW_AUDIT_EXIT_BRIEF_20261110.md, "Sixth reply"); ADOPTED parts only: the drift decomposition (Q1) and the one structural split (Q3). Not adopted: the real-depth test as written (underpowered: per-trade SD 27.9 / 38.6 points, so 100 to 250 events detect only 5 to 11 points), its duration-whiplash reversal of the trader's words, its static cutoffs. SCOPE: the live vacuum rule only (9,116 explore trades 2023-03-07..2025-05-16, RTH and Globex as separate tracks; the builder `scripts/vacuum_sim/vacuum_ml.py build` already matched `calc_outcome`); sealed, depth-era and forward windows are NOT used.
- DESCRIPTIVE (uncounted) DRIFT DECOMPOSITION, gross points signed with the trade direction, no stop and no cost: PRE-EARLY = s x (C[a-3] - C[a-10]); PRE-LATE = s x (C[a] - C[a-3]); POST-1 = s x (C[ei+4] - O[ei]); POST-2 = s x (C[ei+14] - C[ei+4]); POST-3 = s x (C[last] - C[ei+14]) (truncated at the hold end), where a = the signal bar, ei = a + 1; each reported with a day-blocked 95 percent interval, overall and split INSIDE vs OUTSIDE the prior-day value area (inside = PD_VAL <= C[a] <= PD_VAH). A random-direction placebo has expectation zero by construction, so the intervals are compared with zero. Reading: POST-1 clearly negative with PRE windows carrying the move = the entry is late (exhaustion); all post windows flat inside and outside = the trigger is symmetric noise; post drift positive only outside value = location cancels a real edge.
- STRUCTURAL SPLIT (the only counted family, 4 tests, Holm 0.10): for a trigger on track k at the signal bar, with PD_VAH / PD_VAL / PD_POC of the trade date from `level_prices` (the prior day's value area) and ADR20 = mean RTH range of the prior 20 sessions: m = |C[a] - PD_POC| / ADR20. STATE A (open air) = long with C[a] > PD_VAH, or short with C[a] < PD_VAL, AND m >= the median of m over the previous 250 triggers of the same track (chronological, the first 250 triggers of a track are unclassified and excluded from both states). STATE B = all other classified triggers. Outcome = the live-rule result in points, gross of the 2.0 point cost (net + 2.0), the 2.5 x EMA10(TR) stop applied. COUNTED per track: (L1) State A minus State B mean outcome per trade, one-sided H1 > 0; (L2) State A mean outcome against a random-direction placebo at the same timestamps (1,000 draws; the stop is placed on the placebo side), one-sided. Day-blocked bootstrap 3,000 draws; power gate: >= 100 trades on >= 60 days per state per track (else PARKED, not a null). Net of the cost the vacuum is positive only if State A gross exceeds 2.0 points; reported alongside.
- NEXT-STEP TREE: L1 and L2 survive Holm 0.10 and State A gross > 2.0 points -> a forward shadow arm (State A only) on the live detector, judged at a forward floor, nothing wired to orders; L1 survives but gross <= 2.0 -> the location effect is real but too small for the cost: pair with a trade-reduction filter (matched-count control) in a separate row; nothing survives -> the vacuum's flatness is not a location effect on these levels (record the autopsy: which window carried the move).

## RESULT (2026-11-10 night; look 270; `scripts/vacuum_sim/vacuum_location.py`, output `scratch/vacuum_ml_20261110/location_output.txt`): NOT SHOWN; THE WHOLE MOVE IS BEHIND THE ENTRY AND LOCATION RELATIVE TO THE PRIOR-DAY VALUE AREA DOES NOT CHANGE THAT
Holm 0.10 over 4 tests: no survivor. Outcome-blind counts first (look 270): RTH State A 1,083 triggers on 244 days, State B 4,025 on 373 (2,010 unclassified in the 250-trigger warm-up); Globex State A 117 on 70 days, State B 411 on 140 (1,470 unclassified); power gates met for both tracks (Globex only just). Argon's estimate of 1,800-2,400 State A RTH trades was too high.
- DESCRIPTIVE DRIFT DECOMPOSITION (gross points signed with the trade direction, day-blocked mean [95% interval]): RTH, all 7,118 triggers: PRE-EARLY +13.28 [+12.7, +14.0], PRE-LATE +10.92 [+10.4, +11.5], POST-1 +0.03 [-0.3, +0.3], POST-2 +0.07 [-0.3, +0.5], POST-3 -0.43 [-1.0, +0.1]. Inside the prior-day value area (1,960): post windows +0.09, +0.42, -1.23 [-2.4, -0.1]; outside (5,158): +0.01, -0.06, -0.13. Globex, all 1,998: PRE-EARLY +16.53, PRE-LATE +16.98, POST-1 +0.40 [-0.5, +1.3], POST-2 -0.40, POST-3 -0.02; inside/outside similar and inside every interval that contains zero. READING (Argon's own decision rule): the trigger fires after about 24 points (RTH) to 33 points (Globex) of move in the 10 bars before the signal, and the mean drift after entry is zero in every window, inside and outside value: the entry is late, there is neither continuation nor snapback on average, so the gross edge is nil (consistent with -0.2 points gross at the live stop). The one nominal exception is RTH inside value, last third of the hold, -1.23 points [-2.4, -0.1], not a counted test.
- COUNTED STRUCTURAL SPLIT (open air = beyond the prior-day VAH / VAL and at least the rolling median distance from the POC): RTH State A minus State B gross = -0.482 pt per trade [-2.312, +1.284], one-sided p 0.705 (A -0.560, B -0.078; net of the 2.0 point cost A -2.560, B -2.078); placebo comparison p 0.748. Globex +0.337 [-7.431, +8.200], p 0.462 (A +1.370, B +1.033; net A -0.630, B -0.967); placebo p 0.364. L2 used a sign-flip approximation of the random-direction placebo.
- WHAT THIS CLOSES AND WHAT IT DOES NOT: it closes the idea that the plain ROC10 trigger works somewhere on this level geometry (prior-day value area and POC); it says nothing about other locations (weekly / monthly levels, defended pivots at the trigger), the order-book depth version of the original idea (about 100 sessions, underpowered) or Wave 2 entries, all still untested. The flat-after-entry result is also the reason exits, stops and learned policies could not help. Parked per co-025, not retired.
