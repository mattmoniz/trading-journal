## Recommended order of work (value does not depend on finding an edge)
1. Nightly parity-and-attestation job (items 6 and 7 together): replay the last completed session through the research code and compare with the live rows; re-derive P&L and flatness from the broker; write `performance_audit` and raise a banner on divergence. It is also the data source for the Stage 2 review's operational checks (`docs/AMT_TELL_STAGE2_REVIEW_RULE_20261101.md`).
2. Hard gate on new entry orders when the price feed is stale (item 2), reason visible (item 8).
3. Boot self-test of the kill switch and daily-loss gate (item 5).
4. Failure rehearsal script (item 10), run before any real-money step.
5. USER decisions: `DTC_AUTO_REARM_SAFE` = KEEP (decided 2026-11-01; it must never be set on a real-money profile, and any future profile that is not clearly simulated must be explicitly reviewed before it carries the flag); still open: the per-session arming policy for real money (item 4).
Nothing here changes live behaviour by itself; items 1-3 touch live order code or add jobs and need the user's go and the usual review, and any change must be applied with the single-instance restart discipline (a restart disarms the switch).
