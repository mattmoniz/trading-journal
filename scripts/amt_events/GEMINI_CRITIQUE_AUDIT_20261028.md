## Verified and worth adopting
- **Option 1 baseline self-dilution (1.2):** correct algebra. E_TOWARD = mean(y_TOWARD) - mu where mu includes TOWARD itself (43% of RTH explore events), so E = (1 - 0.43) x (TOWARD minus the rest). It shrinks the size of the estimate; it does not by itself explain the +0.022 vs +0.055 gap (the +0.055 compares against matched INSIDE turns only).
- **Trim truncates the treated tail (1.3):** the 90th-percentile threshold comes from donor-donor distances, so far-out treated events are dropped (retained 66% RTH TOWARD, 64% PRIOR_VALUE accepted). The estimand is therefore the effect for "treated events that look like donors".
- **Donors held fixed in the bootstrap (1.4):** a documented simplification; CIs are somewhat too narrow (Gemini's 15-30% is a guess, not verified).
- **553 days that open outside value are excluded from the PRIOR_VALUE family (1.5):** by design (no "first excursion" exists), but it leaves the open-outside regime, AMT's core imbalance case, untested in that form.
- **Acceptance as one 1-minute close at T (1.6)** and **a static 65-point pivot (1.7, inherited from the validated rotation detector):** both real proxies. (Its NQ price levels are wrong: it says about 20,500 in late 2026; the data show about 29,800 and a mean ATR20 of 292.6, so the ATR-share argument is directionally right but its numbers are not.)
- **Ideas to adopt:** time-at-price (TPO 30-minute bracket) acceptance; hindsight-free checkpoints (classify at 10:00 / 10:30 / 11:30 and measure only what follows); structural outcomes (traversal of value, IB extension multiple, extreme breach) instead of fixed-clock drift; excess / poor extremes; opening type vs IB extension; an ATR-scaled-pivot redo of option 1 with the matched INSIDE contrast as the primary; open-outside-value as its own family.

## Wrong or overstated
- **"Fatal" cross-direction matching in option 3 (1.1): overstated.** y is already signed along the excursion direction, so an up-accepted event and a down-rejected donor are comparable. Tested on explore (diagnostic only, hold-out untouched): matching WITHIN direction gives PRIOR_VALUE D -0.009 (CI -0.086..+0.068) vs as-run +0.003, and IB D -0.026 (CI -0.058..+0.007) vs as-run -0.023. No material change. A narrower true point: the matching uses |gap|, which ignores whether the gap is with or against the excursion. "Option 3 null is completely uninformative due to fatal coding flaws" is therefore too strong; its remaining weakness is the single-close acceptance proxy.
- **"The 80% rule has not been covered" is wrong.** `vbp_prior_va_reentry_far_side_not_shown_20261027` (VBP Test B: first 30-minute cell back inside the prior RTH value area with the next cell also inside, reach the far side; 159 RTH events, reach -1.1 points vs matched blind, lower bound -9.5) is the same construct with the volume-based value area. Gemini's Test 1 is the TPO-value-area version of it: a genuine fidelity upgrade, not an untouched idea.
- **Friction:** it states "1.0 pt slippage + $1.24 round-turn commission"; this repo's ground truth is MNQ $2.00 round trip (`server/config/instruments.js`).
- **"Descriptive AMT is proven ... genuine reference points for institutional inventory":** conflates description (where trade occurred, trivially true) with a predictive claim (that those levels act as reference points). Its unsupported asserted "in hindsight discretionary memory" explanation is opinion.
- **Its alternative** (overnight inventory skew + opening-range expansion) re-proposes ground this repo has already covered (overnight context Part A, overnight order-flow entry, opening-drive gate), and "vastly stronger empirical foundation" is asserted, not shown.
- **Its proposed program breaks this project's rules:** static cutoffs (85% overnight volume, 0.35 ATR open drive, "traversal >= 65% vs a 50% baseline", "breach rate 15% higher", "CI lower bound > 0.10 ATR20") instead of data-derived thresholds; a 50% binomial baseline is the wrong baseline for traversal (the matched-control rate is); expected-event counts are guesses; Tests 3-5 have about 75-160 events, which cannot confirm effects as small as it names. Treat it as a menu of constructs, not a prereg.
- **Hold-out:** its "reserving 40% costs 29% wider CIs for no benefit" ignores that opening the hold-out on a null is itself a forking cost and that an unopened hold-out can serve the next hypothesis.
- **Closing rhetoric** ("spent 850 sessions proving what quantitative finance already knows") is unsupported.
