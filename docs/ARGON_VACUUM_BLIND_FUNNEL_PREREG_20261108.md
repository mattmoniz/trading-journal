## 3. Definitions (Argon High audit fixes applied; every one is causal)
- RTH slice per file: keep bars with start_sec >= 55800 and end_sec <= close_sec (79200 = 16:00 ET; early-close days from `event_calendar` EARLY_CLOSE rows, 13:15 ET = 69300), complete == 1, vol == 500. The one bar straddling 09:30 and any bar closing after the cutoff are dropped. Re-index 0..N-1; TR[0] = high-low, EMA_TR[0] = TR[0]. A session qualifies only with N_rth >= 60 (7 of 536 days fail, e.g. 2023-03-07/08 pre-roll thin contract).
- Inclusion and entry windows gate on end_sec (a bar is observable only at its close): entries from end_sec >= 56100 to close_sec - 600; hard flat bar = last bar with end_sec <= close_sec - 300 (used only to clamp horizons in later stages).
- Priors for session s use the 20 prior qualifying sessions s-20..s-1 only (never s): ATR_20d = mean session high-low, session-equal-weighted quantiles of Activity and CLV, BaseDur = median of per-session medians of dt.
- dt_raw = end_sec - start_sec at 1 ms resolution; floor_d = max(Quantile_eq_0.01(dt_raw[dt_raw >= 0.001]), 0.005); dt = max(dt_raw, floor_d); Activity = BaseDur / dt.
- Delta = ask - bid per bar; flag days with sum(bid+ask)/sum(vol) < 0.95. Halt rule: if start_sec[k] - end_sec[k-1] > 300 or end_sec[k] - start_sec[k] > 300 in RTH, reset state to FLAT and re-seed warmup and EMA_TR.
- Strict v2 funnel exactly as in spec section 3-5 with its constants (Efficiency 0.45, DeltaImb 0.15, Disp = max(0.10 ATR, 2.5 EMA_TR, 10 x 1.5 pt), Activity q 0.60, zone 0.25-0.50, reclaim 2 bars, max_pb_bars from the trailing uncensored scanner, the init_risk > 0.35 ATR and anti-chase aborts, entry_ref = close[k]); FAST_FLOW_CONTROL as in spec section 6.2.3. NO other variant is counted; no constant is changed after the counts are seen (any change needs a new pre-registration charged to the multiplicity family).

## 4. Outputs (no forward price of any trigger)
A. Per session and in total: Wave-1 arms, pullback reaches, triggers (long/short, by hour_et), active days, trigger-weighted effective active days N_eff = (sum_d m_d)^2 / sum_d m_d^2; the same for FAST_FLOW_CONTROL.
B. Paired correlation, outcome-free: per day, each arm's signed forward-exposure vector w_A[b] = (1/m_A) sum_i dir_i * 1(t_i < b <= t_i + 30, clamped to the hard-flat bar); rho_day = mean_d <w_C,w_F> / sqrt(mean_d ||w_C||^2 * mean_d ||w_F||^2) over jointly active days. Reads no price. The intra-day cluster factor comes from ||w_C||^2 / 30.
C. sigma_day: the day-clustered standard deviation of the 30-bar forward close-to-close change over fast-tape RTH active-window bars (Activity >= trailing q60), unconditional of any trigger (blind to vacuum, pullback and reclaim). Logged as a ledger look (family `argon_vacuum_blind_funnel`, 0 counted tests, note: unconditional volatility).

## 5. Power gate (frozen now; Argon High numbers, derived from MDE = 2.802 * sigma_day / sqrt(N_active_days))
RESOLVABLE ON EXPLORE only if ALL hold: (i) triggers per qualifying session >= 0.70; (ii) active days >= 250; (iii) pooled MDE <= 3.50 pt (1.75x the 2.0 pt all-in cost floor: 1.00 pt commission + 0.25 x (entry + exit slip ticks)); (iv) paired MDE vs FAST_FLOW_CONTROL <= 3.00 pt using the measured rho_day; (v) N_eff >= 180 and >= 40 triggers in each Explore third. These are resolvability thresholds for Explore alone, NOT a judgement on the idea.

## 6. Outcome tree (co-022, co-025: nothing is retired)
