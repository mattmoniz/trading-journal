# Pre-registration: the STOP_SWEEP mechanism (stops resting beyond key levels get run, then price reverses) — replay, placebo, and the 10am timing — 2026-10-21

Written and committed BEFORE any outcome is computed. Origin: user (2026-10-21): the reversal sweep "is called a stopsweep, it usually happens around 10am… it's an actual mechanism" (message cut off after "that"). The FAILED_SWEEP_REVERSAL study (`docs/FSR_REEVAL_AND_TIGHTENING_PREREG_20261021.md`) tested a looser cousin (pivot/POC levels, no confluence, 68/250); that did not show the sweep signal adds anything over a flipped-direction placebo. This tests the real StopSweep rule. Research only, nothing live changes; the setup is paused (`STOP_SWEEP_PAUSED`) pending a target re-calibration and stays so.

## The live rule (read from `server/routes/acd.js` ~5514, not assumed)
RTH, 1-minute bars, needs 30 RTH bars (so not before about 10:00), last 10 bars. Sweep levels in this order: ONL (overnight low), ONH, PDL (prior-day RTH low), PDH, IB_LOW, IB_HIGH. A level counts only if another key level is within 30 points of it (the confluence gate: prior-day VAH/VAL/POC, floor S1/R1/pivot, prior-week low/high/VAH/VAL). LONG: a bar in the last 10 traded more than 3 points below the level, price is back above it, the sweep extension (level minus lowest low) is between 3 and 50 points, and the bounce (price minus that low) exceeds 15. SHORT mirrors. Live trade: stop 5 points beyond the sweep extreme, target 30 points (a flat literal, the reason it is paused). Real exits are STOP_HIT, TARGET_HIT, TIME_EXPIRED.

## Replay (same machinery as the FSR replay)
NQ 1-minute RTH bars 2023-03-06 to 2026-10-20, the same dropped sessions (roll weeks, 2025-09-28 to 2025-11-19). Levels and confluence levels from `level_prices` (ONL, ONH, PD_LOW, PD_HIGH, IB_LOW, IB_HIGH; confluence: PD_VAH, PD_VAL, PD_POC, FLOOR_S1, FLOOR_R1, FLOOR_PIVOT, PW_LOW, PW_HIGH, PW_VAH, PW_VAL; a level does not count as its own confluence). IB_LOW/IB_HIGH only from 10:31 (the value in the table is the finished day's; before the hour is over it is lookahead). Event at the close of bar t, first level in the live order that matches, edge-triggered per level and direction, one open replay position per direction; entry = event bar close. Fidelity (reported first): the share of real RTH-fired StopSweep rows since 2026-07-10 that line up with a replay event (same direction, within 10 minutes) and the reverse, and the outcome-class agreement when they do.
Exits, all reported (same-bar tie goes to the stop, stop fills at the bar open if gapped through): V1 the live exit (stop 5 beyond the sweep extreme, target +30, otherwise the 15:58 close); V2 structural stop only (same stop, no target, hold to 15:58); R-race: first to +k R or -1 R for k = 1, 2, 3, 5 where R = entry-to-stop distance, unresolved at the close marked at the close in R. Dollars = points x 2 - 2.

## Tests (frozen)
- **S1 does the mechanism add anything beyond geometry and drift:** flipped-direction placebo on the same events (entry the same, stop and target distances mirrored in the opposite direction). For V2 mean dollars and the R-race at k = 3: real minus flipped, day-blocked bootstrap 95 percent interval, explore (to 2025-05-31) and hold-out (2025-06-01 on) separately. SUPPORTED only if the interval is above zero in both periods for V2 dollars AND for the k = 3 R-race expectancy; otherwise NOT SHOWN, stated as what could not be shown.
- **S2 the 10am timing:** events entered 10:00-10:30 versus entered later (11:00 for the IB levels cannot fire before 10:31, so they are excluded from S2): V2 mean R and k = 3 R-race expectancy, difference with a day-blocked interval, explore and hold-out. TIMING MATTERS only if the interval excludes zero on the favourable side in both periods.
- **S3 exploratory (reported, no verdict):** the same replay with the 30-bar gate removed (events from 09:35, since ONL/ONH/PDL/PDH exist before the open), to see whether the live gate excludes the best window; by level; by direction; the home-run view (share reaching 3R and 5R before the stop and the mean R of those).
- Comparisons: S1 x 2 metrics x 2 periods, S2 x 2 metrics x 2 periods; 95 percent intervals. A cell with fewer than 20 events or 20 distinct days is underpowered, not a verdict.

## Known limits (stated in advance)
Replay approximates a 15-second poller (bar-close entry, edge trigger); ONL/ONH in `level_prices` are computed over the overnight session whereas the live query uses the calendar-day bars before 09:30, so the levels can differ slightly; the live setup has only about 110 real RTH rows; the user's mechanism may include features not in this rule (order-flow, volume, the specific stop cluster) and a null here would be a null for this rule only; nothing here changes the pause or the target decision (`OPEN_DECISION stop_sweep_long_calibrated_target_pause_or_keep` follows its own path).

## Addendum (written after the first replay run showed fidelity of only 7 percent, before the corrected run is read)
The first run (`scratch/stop_sweep_replay_20261021.txt`) reported: replay V1 mean -3.1, flipped-direction placebo comparison not shown, 10:00-10:30 entries worse than later ones. Only 7 percent of the 109 real RTH StopSweep rows lined up with a replay event, so it did not reproduce the live rule. Diagnosis from the real rows: the live ONL/ONH are the calendar-day bars before 09:30 (so only after midnight), while `level_prices` ONL/ONH cover the whole overnight session (one real ONL long on 2026-08-21 has a sweep extreme ABOVE the table's ONL, impossible for that level), and `level_prices` is missing IB rows on several recent dates. Correction, applied before the corrected run is read: ONL/ONH = min low/max high of that calendar date's bars before 09:30; PD_LOW/PD_HIGH = the previous session's RTH low/high from the bars; IB_LOW/IB_HIGH = 09:30-10:29 low/high from the bars, used from 10:31. The confluence levels still come from `level_prices`. All tests, exits and rules above are unchanged. If fidelity is still below 50 percent after this, every result is described as a result for a similar rule, not the live one.
