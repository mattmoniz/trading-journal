# ML meta-labeling: which levers matter (synthesis, 2026-10-25)

User concern (2026-10-25): "I don't know which levers to pull for most impact. 22 is a lot." This page ranks the levers using ONLY pre-registered work already in the repo (no new computation); every number is from the cited RESEARCH_CLAIM. Noise band: 8 null-column arms, AUC SD 0.0039, policy SD 0.235 per trade; dollar intervals are about +/-1 per trade, so no dollar difference between model variants has ever been shown.

## 1. Inputs (the 22): about 4 columns do the work
| Group | Removal effect on AUC (baseline 0.5859) | In dollars | Source |
|---|---|---|---|
| Time in session (`barsInSession`, `minutes_from_open`) | -0.030 (7.6 null SD) | not significant | `ml_input_ablation_and_candidates_20261020` |

| Developing-level distances (4), value migration (3) | within noise | none | same |
| Candidate new inputs (day type, order flow vs normal, rotation gate/chop, family, ONH/ONL, prior-week levels) | each within noise or inside matching-control noise (best: ONH+ONL +0.011 AUC, dollars not shown) | none | `ml_input_ablation_...`, `ml_level_distance_features_...`, `ml_setup_family_input_not_shown_20261020` |

A 17-input model (drop prior-day structure, confluence, direction) has AUC 0.5986 and is "simpler and not distinguishable" in dollars; a 4-input model (time + delta15) is worse on AUC (0.570). So: the 22 can safely be cut to about 17 with no detectable loss, but **input pruning is not a profit lever** (`ml_pruned_models_not_distinguishable_20261020`).

## 3. Reading
There is no lever with a demonstrated dollar effect. The only items with a measured, non-noise signal are (a) time-in-session and recent order flow as discriminating inputs (AUC only), and (b) a hint that the gate helps RTH and hurts Globex. The LIVE_ROSTER gate already removed most of what ML was filtering (the account-level value of the gate was trade avoidance on a negative roster, `ml_dollar_trained_gate_not_shown_20261020`).
