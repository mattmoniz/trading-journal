# ML ranking test (pre-registered 2026-10-06, `ml_ranking_preregistered_test_20261027`): addendum fixing the undefined details — 2026-10-25

Written BEFORE the test window (2026-10-07..2026-10-27) is complete, so the choices below cannot be tuned to the answer. The original pre-registration (PURPOSE, CUTOFF 2026-10-07, TEST WINDOW, DECISION WINDOWS, METRIC, PASS BAR) is unchanged and quoted in the decision text. What it left open:
1. **Which model.** The pre-registration predates the 2026-10-25 cut to 4 inputs. PRIMARY = the model design now live: `CORE_COLS` (4 inputs: `intraday_barsInSessionSoFar`, `minutes_from_open`, `intraday_recentDelta15Bars`, `drv_recentDeltaAligned15Bars`), trained fresh on `ml_extended_label` rows fired before 2026-10-07 minus the walk-forward purge (`PURGE_DAYS`), hyperparameters from `load_hyperparams`, the same sample weights as `train.py`. SECONDARY (information only, cannot decide the verdict) = the 22-input model (`feature_cols(full=True)` minus `TRIMMED_COLS`) trained the same way.
2. **Test trades.** `active_setups` rows with `origin_status='ACTIVE'`, `is_cluster_primary IS NOT FALSE`, `actual_pnl` not null, `bad_bars_basis IS NOT TRUE`, resolved, fired from 2026-10-07 00:00 through 2026-10-27 23:59:59 (ET), that also have a full feature snapshot (rows without one cannot be scored; their count is reported). POC_ROTATION_JOIN rows are INCLUDED only if they meet these filters (they are force-SHADOW since 2026-10-21, so almost none are ACTIVE).
3. **Decision windows.** Trades sorted by `fired_at`; a window is a maximal chain in which each trade fired within 5 minutes of the previous one; windows with 2 or more trades count.
4. **Metric.** Per window: top-ranked = highest model probability (ties broken by earliest `fired_at`); random baseline = the mean pnl of the window's trades (the expected pnl of a uniformly random pick). Average over windows of (top pick pnl − window mean) is the "beats random by $X per window"; "beats random in a window" = top pick pnl strictly greater than the window mean. A day-blocked (by window date) bootstrap CI of the mean difference is reported for information.
5. **Pass bar (unchanged).** At least 20 windows; mean difference >= +$5; beats random in >= 60% of windows. All three on the PRIMARY arm. FAIL = ML dropped as a ranker, scores kept for logging only. Result recorded with `recordClaim` either way, and the decision resolved with the numbers.
6. **When it runs.** Automatically on or after 2026-10-28 (the window must be closed and trades resolved), once; `scripts/run_ml_ranking_test_20261027.mjs` has the date guard and refuses to overwrite a recorded result without `--force`. A dry run before that date is for testing the code only and is never recorded.
